## 문제 1. 6주차 강의자료 [문제 6-1]

실수(real)부와 허수(imaginary)부를 갖는 복소수 `Complex` 클래스를 다음 조건에 따라 정의한다.

- **기본 생성자:** 멤버 변수 `real`, `image`의 값을 각각 1로 초기화한다.
- **매개변수 2개 생성자:** 생성과 동시에 정수 인자 2개를 주면, 그 인자 값으로 `real`, `image`를 각각 초기화한다.
- **set 멤버 함수:** `private`인 실수부와 허수부의 값을 각각 수정할 수 있는 set 멤버 함수를 추가한다.
- **`pCom()` 멤버 함수:** `private` 멤버 변수를 화면에 출력한다.
- **동적 생성:** 복소수 객체 2개를 각각 동적으로 생성한다.
- **이름 규칙:** 멤버 변수의 이름과, 생성자와 멤버 함수의 매개변수 이름을 모두 `real`, `image`로 같게 쓴다.

`main()` 함수는 다음 뼈대에 따라 작성한다.

```cpp
int main() {
    // Complex 동적 첫 번째 객체 생성 (초기값 정보 없음). 포인터 a로 관리
    // Complex 동적 두 번째 객체 생성 (초기값 정보 없음). 포인터 b로 관리
    // 포인터 a, b로 관리되는 Complex 동적 객체의 정보 출력.
    // 첫 번째 객체의 real 값을 4로 업데이트
    // 두 번째 객체의 image 값을 9로 업데이트
    // 2개의 동적 객체 배열의 정보 출력
    // 동적 메모리 해제
}
```

## 문제 2. 6주차 강의자료 [문제 6-2]

회원 정보를 관리하기 위하여 다음 정보를 갖는 `Member` 클래스를 구현하고 `main()` 코드를 완성한다.

- **`private` 멤버 변수:** `name`(`string`), `id`(`string`), `age`(`int`)
- **기본 생성자:** `"noname"`, `"none"`, 0으로 멤버 변수를 초기화한다.
- **인자가 3개인 생성자:** 3개의 인자로 `name`, `id`, `age`를 초기화한다.
- **set 함수:** `private` 멤버 변수의 값을 각각 수정할 수 있다.
- **get 함수:** `private` 멤버 변수의 값을 각각 이용할 수 있다.
- **`printM()` 함수:** `name`, `id`, `age`를 화면에 출력한다.

`main()` 코드는 다음 순서로 동작한다.

1. `Kim` 객체를 생성한다.
2. `Lee` 객체를 초기값 {Lee Hi, 2016001, 22}로 생성한다.
3. `Kim`, `Lee` 객체의 정보를 화면에 출력한다.
4. `Kim` 객체의 정보를 {Kim Haha, 2016020, 29}로 수정한다.
5. `Kim` 객체의 정보를 화면에 출력한다.

## 문제 4. 6주차 강의자료 [문제 6-5]

다음과 같이 원을 추상화한 `Circle` 클래스가 있다. 사용자로부터 원의 개수를 입력받은 후 그 크기의 `Circle` 객체 배열을 동적 메모리에 생성한다. 이어서 각 원의 반지름을 입력받은 후, 면적이 100 이상인 원의 개수를 출력한다.

```cpp
class Circle {
    int radius; // 원의 반지름 값
public:
    void setRadius(int radius); // 반지름을 설정한다.
    double getArea(); // 면적을 리턴한다.
};

void Circle::setRadius(int radius) {
    this->radius = radius;
}

double Circle::getArea() {
    return 3.14*radius*radius;
}
```

`main()` 함수는 다음 뼈대에 따라 작성한다.

```cpp
int main() {
    // Circle 동적 배열을 관리할 수 있는 포인터 p 선언
    // Circle 동적 배열 크기 정보 화면에서 입력 받음
    // 입력 받은 크기의 동적 배열을 생성하고, p로 관리
    // 입력 받은 크기의 개별 객체의 반지름 정보 입력 받음
    // 면적이 100 이상인 원 카운팅.
    // 해당 정보 화면 출력
    // 동적 메모리 해제
}
```

**실행 예시** (원 5개의 반지름으로 3, 7, 2, 9, 1을 입력한 경우)

```text
원의 개수 >> 5
원 1의 반지름 >> 3
원 2의 반지름 >> 7
원 3의 반지름 >> 2
원 4의 반지름 >> 9
원 5의 반지름 >> 1
면적이 100보다 큰 원은 2개 입니다
```
