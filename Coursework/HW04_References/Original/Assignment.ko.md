## 문제 1. 9주차 강의자료 [실습 문제 2]: MyIntStack 코드 구현 및 분석

정수를 저장하는 스택 클래스 `MyIntStack`을 다음 선언대로 구현하라. 스택에 저장할 수 있는 정수의 최대 개수는 10이다.

```cpp
class MyIntStack {
    int p[10];
    int tos; // 스택의 꼭대기를 가리키는 인덱스
public:
    MyIntStack();
    bool push(int n); // 정수 n 푸시. 꽉 차 있으면 false, 아니면 true 리턴
    bool pop(int &n); // 팝하여 n에 저장. 스택이 비어 있으면 false, 아니면 true 리턴
};
```

배열을 스택처럼 쓰도록 코드를 작성하며, 스택의 의미는 인터넷에서 찾아 확인할 수 있다. 각 멤버 함수가 할 일은 다음과 같다.

- **생성자:** 처음 객체가 생성될 때에는 스택에 쌓인 정보가 없으므로 `tos`를 0으로 설정한다.
- **`push()`:** 호출할 때 전달된 정수를 스택에 저장하고, 저장에 성공하면 `true`를 리턴한다. 스택에 쌓인 정보가 최대 개수에 이르러 더 저장할 수 없으면 `false`를 리턴한다.
- **`pop()`:** 스택에 쌓인 정보를 참조 매개변수에 전달하고, 성공하면 `true`를 리턴한다. 더 꺼낼 정보가 없으면 `false`를 리턴한다.

`main()`은 다음과 같다. 저장할 수 있는 범위(10개)를 벗어나면 어떻게 처리되는지 확인하기 위해, 푸시와 팝을 10번이 아니라 11번 시도한다.

```cpp
int main() {
    MyIntStack a;
    for (int i = 0; i < 11; i++) {   // 11개를 푸시한다
        if (a.push(i))
            cout << i << ' ';        // 푸시된 값 에코
        else
            cout << endl << i + 1 << " 번째 stack full" << endl;
    }
    int n;
    for (int i = 0; i < 11; i++) {   // 11개를 팝한다
        if (a.pop(n))
            cout << n << ' ';        // 팝한 값 출력
        else
            cout << endl << i + 1 << " 번째 stack empty";
    }
    cout << endl;
    return 0;
}
```

강의자료는 설명의 편의를 위해 같은 코드를 한 쪽에 모은 판도 보여 준다. 이 판은 스택의 크기 10을 2로 줄여 매크로 상수 `MAX`(`#define MAX 2`)에 두고, 두 `for` 문을 `MAX + 1`번 반복하며, 출력 문구를 `번째 시도 stack full`, `번째 시도 stack empty`로 바꾸고, 두 반복 사이에 구분선을 출력한다.

**실행 예시** (`MAX`가 2인 판)

```text
0 1
3 번째 시도 stack full
-----------------------
1 0
3 번째 시도 stack empty
```
