## 문제 3. 예습: 5주차 강의자료 p.15 코드 분석

다음은 동적 메모리의 할당과 반환을 보이는 5주차 강의자료의 코드이다. 이 코드가 하는 일을 분석한다.

```cpp
#include <iostream>
using namespace std;

int main() {
    int size;
    cout << "Input size: ";
    cin >> size;

    // int arrStatic[size] = { }; 일반 변수: 가능한가?
    int arrStatic[4] = { 1, 3, 5 };

    for (int i = 0; i < 4; i++)
        cout << arrStatic[i] << ' ';
    cout << endl;

    // 동적 메모리는 가변 길이 배열 선언 가능
    int* pDynamic = new int[size];

    for (int i = 0; i < size; i++)
        pDynamic[i] = i * 3;

    for (int i = 0; i < size; i++)
        cout << pDynamic[i] << ' ';
    cout << endl;

    delete[] pDynamic;
    // pDynamic = NULL;
    pDynamic = nullptr;
}
```

**실행 예시** (`5`를 입력한 경우)

```text
Input size: 5
1 3 5 0
0 3 6 9 12
```

강의자료는 10행에 대하여, 일반적인 배열은 고정 크기로 생성해야 하며 동적 배열이나 `vector`를 활용하면 가변 길이 배열을 생성할 수 있다고 덧붙인다. 9행의 주석은 크기를 일반 변수로 정한 배열을 선언할 수 있는지 묻는다.
