## 문제 1. 이론 교재 3장 실습 문제 3번

은행에서 쓰는 프로그램을 작성하려면 은행 계좌 하나를 표현하는 `Account` 클래스가 필요하다. 계좌 정보는 계좌의 주인, 계좌 번호, 잔액을 나타내는 세 멤버 변수로 이루어진다. 다음 `main()` 함수가 실행 예시처럼 출력하도록 `Account` 클래스를 작성하라.

```cpp
int main() {
    Account a("kitae", 1, 5000);   // 계좌 번호 1, 잔액 5000원, 주인이 kitae인 계좌 생성
    a.deposit(50000);              // 50000원 입금
    cout << a.getOwner() << "의 잔액은 " << a.inquiry() << endl;
    int money = a.withdraw(20000); // 20000원 출금, withdraw()는 출금한 금액을 리턴
    cout << a.getOwner() << "의 잔액은 " << a.inquiry() << endl;
}
```

**실행 예시**

```text
kitae의 잔액은 55000
kitae의 잔액은 35000
```

## 문제 2. 이론 교재 3장 실습 문제 5번

랜덤 정수를 발생시키는 `Random` 클래스를 작성하라. `Random` 클래스는 생성자와 멤버 함수 `next()`, `nextInRange()`를 가진다. `next()`는 0 이상 `RAND_MAX` 이하의 랜덤 정수를, `nextInRange(s, f)`는 `s` 이상 `f` 이하의 랜덤 정수를 리턴한다. 다음 `main()` 함수와 함께 하나의 cpp 파일로 작성한다.

```cpp
int main() {
    Random r;
    cout << "-- 0에서 " << RAND_MAX << "까지의 랜덤 정수 10개 --" << endl;
    for (int i = 0; i < 10; i++) {
        int n = r.next();              // 0에서 RAND_MAX 사이의 랜덤한 정수
        cout << n << ' ';
    }
    cout << endl << endl << "-- 2에서 " << "4까지의 랜덤 정수 10개 --" << endl;
    for (int i = 0; i < 10; i++) {
        int n = r.nextInRange(2, 4);   // 2에서 4 사이의 랜덤한 정수
        cout << n << ' ';
    }
    cout << endl;
}
```

교재는 다음 두 가지를 힌트로 준다. 랜덤 정수는 `<cstdlib>`의 `rand()`로 발생시키고, 실행할 때마다 다른 수가 나오도록 `<ctime>`의 `time()`으로 `srand((unsigned)time(0));`처럼 시드를 정한다. `RAND_MAX`는 `<cstdlib>`에 정의된 상수이다. 출력은 안내 문구 한 줄과 공백으로 구분한 랜덤 정수 10개 한 줄이 두 번 반복되는 형식이며, 값은 실행할 때마다 다르다.

## 문제 3. 4주차 강의자료 [문제 1-3]

다음과 같이 출력되도록 점(point)을 표현하는 `Point` 클래스를 작성하고 실행하라. `Point` 클래스의 구성은 다음과 같다.

- **`private` 멤버 변수:** 좌표 `int x, y;`
- **기본 생성자:** 멤버 변수 `x`와 `y`를 0으로 초기화한다(선언과 동시에 정의).
- **인자 2개 생성자:** 전달된 두 정수로 `x`, `y`를 초기화한다(선언과 정의를 구분).
- **좌표 정보 출력 함수 `showP()`:** 선언과 정의를 구분한다.
- **`x`의 get/set 함수:** 선언과 동시에 정의한다.
- **`y`의 get/set 함수:** 선언과 정의를 구분한다.

`main()` 함수의 뼈대는 다음과 같으며, `// 생략` 부분에서 `p2`의 좌표를 입력받아 설정한다.

```cpp
int main() {
    Point p1, p2;
    int temp;

    cout << "Input p2.x: ";
    // 생략

    cout << "Input p2.y: ";
    // 생략

    cout << "p1. ";
    p1.showP();
    cout << "p2. ";
    p2.showP();
}
```

**실행 예시** (`-3`과 `4`를 입력한 경우)

```text
Input p2.x: -3
Input p2.y: 4
p1. x: 0, y: 0
p2. x: -3, y: 4
```

강의자료는 앞의 [문제 1-1], [문제 1-2]에서 같은 `Point` 클래스를 단계적으로 다룬다. [문제 1-1]은 두 점의 좌표를 입력받아 `<cmath>`의 `sqrt()`로 두 점 사이의 거리를 출력하고, [문제 1-2]는 기본 생성자, 인자 2개 생성자, `showP()`를 갖춘 `Point` 클래스로 `Point p1;`과 `Point p2(3, 4);`의 좌표를 출력한다. 문제에 접근 제어에 관한 표현이 없으면 멤버 변수와 멤버 함수는 `public`으로 둔다. [문제 1-3]은 여기에 `private` 접근 제어와 get/set 함수를 더한 것이다.
